## Tecnologias utilizadas

- React Versão: 19.2.8
- Typescript
- Material UI Versão: 9.3.1
- Axios
- Vite
- Zod
- React Hook Form
- Sonner
- Date-fns
- React Router Dom

## Como rodar a aplicação

Requisitos: Node.js >= v24.13.0

```bash
cd frontend
```

```bash
npm install
```

```bash
npm run dev
```
